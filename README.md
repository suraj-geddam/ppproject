# ppproject

> Made during my undergrad (Parallel Programming Paradigms, Spring 2018), pls don't look at the code lol

A couple of experiments from back then:

- `ldamulticore.py` / `ldadist.py`: timing gensim's multicore LDA against its distributed LDA on the same corpus (`results.txt` has the numbers).
- `passwordsafety.py`: brute-forcing a list of MD5 password hashes, to see how quickly weak passwords fall.
